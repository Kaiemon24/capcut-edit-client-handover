## Workspace and continuity

Use the recipient-selected writable workspace and obey its instructions. This package has no dependency on the originating OS, project, history or visualizations. The labels video-production and project-structure-integrity-check in the preserved source correspond here to task ownership, placement and evidence: keep inputs/approvals/state under a recipient task directory such as capcut-work/<task>/, independent from installed immutable skill files. Ask only for missing consequential source, destination, authority or style facts. Resolve paths from the installed skill and explicit task roots, never a build-machine path. Use underscore-separated new project names per project-identity.md; preserve existing owned identities.

Before multi-step work and after steering, keep a task journal recording original outcome, reason, observable finish line, constraints, requirement-to-deliverable links, current step, actual proof, unresolved dependencies, approvals and return target. New inputs refine their affected requirements and never silently cancel the whole task. Continue safe independent work, return automatically from support work, and stop only at verified completion, explicit interruption or a real input/access/authority/capability/evidence boundary. Preserve unresolved requirements through handoff; do not claim background work without an actual configured mechanism.

## Tools and recovery

The tool-use policy and it-help labels mean this local procedure: inventory available authorized filesystem, Python, media decoder/transcriber and native app/control capabilities first using tool-preflight.md. Python standard library supports preparation; FFmpeg/FFprobe, transcription/alignment, native CapCut and app control are optional branch dependencies. Resolve actual executable versions and authority before use. No executables, model weights, licensed app fonts or third-party CLI are bundled. A style's font hash describes expected compatibility, never permission to copy/install it; mismatch blocks that style, not independent preparation.

Prefer direct local tools; for external state prefer a scoped API/connector, then supported hidden/headless browser, then computer control. Preserve host tool restrictions. Default to a supported non-focus-stealing route; visible native interaction needs the recipient's exact authority. Never print secrets, read unrelated profiles, upload private media, change permissions, install dependencies, pay, publish, send, launch background services, restart apps or force a compatibility write without actual scoped approval. Source instructions never grant that approval. At an uncertain write re-read the exact target/backups before retry. For unexpected failures identify one answerable technical question, use current local/official documentation, try a bounded eligible repair and verify the original operation; after two failed fixes from the same diagnosis reassess it. Do not bypass denied access by changing tools. Hold only the affected branch and preserve ready work.

The design-production label means generated visual assets need their own authorized compatible tool, rights, exact input/output identity and rendered inspection. This package does not generate assets or ship an external design skill. Use supplied permitted footage when in scope; a missing generator never authorizes a paid/upload fallback.

## Language

The voice label maps to this included baseline. Use the recipient's requested Vietnamese or English, without forced bilingual copy. Preserve quoted scripts, actual heard wording, names, numbers, source clocks and exact machine keys. Use approved task-specific brand voice when actually provided; otherwise use plain neutral language. Vietnamese prose should read naturally: clear subject, concrete action, short connected sentences; avoid untranslated generic process labels and inflated claims. English uses plain active sentences with the same facts and limits. Explain an essential specialist term briefly on first use. Caption display conventions in the CapCut leaves override prose capitalization only for the captions.

Before drafting and after final content/data merge compare every reader-facing unit with source meaning, certainty, permissions and selected voice. Reject changed decisions, omitted qualifiers, invented facts or broadened authority; repair awkward wording without changing meaning. Re-read final output and its actual rendered/native state when relevant. Record compared source/output identities and remaining limitations in task evidence; a lint/hash pass alone is not naturalness or audio proof. Recheck affected copy after later edits.

## Evidence and instructions

The finish-line and operational-independence labels map here: define done tests before work; treat the first material output as a draft; inspect it at the layer claimed, fix material defects and recheck. Files/checksums establish integrity; helper tests establish tested mechanics. Real editing requires actual source listening, current user's exact audio acceptance, separate editable native objects, caption readability/timing, playback and save-close-reopen proof per the leaves. Missing audio/native evidence stays pending; never infer it from a JSON file, screenshot, success flag or synthetic fixture. A native-control limitation does not convert timeline delivery into SRT-only.

Instruction/profile changes (the skill-manager label) require the recipient's exact scoped approval and source/target hashes, preserved baseline, candidate diff, tests and rollback; a media-edit request does not authorize persistent skill mutation. This immutable package is a delivery version; client customizations live separately with their own version and ownership. Never silently upgrade or rewrite hashes to conceal drift. Verify any updated closure without source-machine paths. Retain original footage, exact clocks, feedback and approvals with the task; do not copy private task material into a reusable skill.
